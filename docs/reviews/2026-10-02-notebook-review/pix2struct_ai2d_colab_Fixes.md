## User-visible changes

- BYOD zips are extracted with their folders kept; `image` paths are relative to the records file, which may sit at the root or inside one folder. A zip with no or several records files, a member path outside the zip, more than 5,002 members or more than 2 GiB extracted is refused with the zip and the rule named. The old flat extraction (and its "image file not found" message for nested paths) is gone.
- Section 6 prints `adapted` and stops if the pipeline it scored carries an adapter; Section 8 prints `scored_weights`.
- A new optional experiment cell (`RUN_OPTION_SHUFFLE_EXPERIMENT`, default `False`) before the closing; under Run all it prints `skipped`.
- The notebook declares NOTEBOOK_SPEC 2.2; carried-module cells carry a `# @title Infrastructure` comment line; the Prerequisites state the recorded T4 duration and a labelled CPU estimate; the BYOD and optional-experiment instructions name the cells to re-run.
